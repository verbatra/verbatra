## Qué acaba de pasar

- `verbatra.lock.json` guarda un hash de cada texto de origen, para que la siguiente ejecución envíe solo textos nuevos y modificados. Consulta [El archivo de bloqueo](/docs/the-lock-file).
- Un resultado que pierde un marcador de posición se retiene y nunca se escribe. Consulta [Seguridad de la traducción](/docs/translation-safety).

Haz commit de los archivos de locale, `verbatra.lock.json` y `verbatra.provenance.json` juntos.

## Opcional: conecta tu agente de programación

<AvailableFrom version="0.12.0" />

```bash
npx @verbatra/cli init --agent
```

Con la configuración ya creada, `init --agent` la conserva y añade solo los archivos del agente: las reglas de verbatra en `AGENTS.md` (o `CLAUDE.md`, cuando es tu único archivo de instrucciones) y el servidor MCP de verbatra, sin las herramientas que gastan, en la configuración de proyecto de cada agente de programación que detecta. Qué archivos escribe para cada agente, y cómo eliges tú los agentes con `--client`, está en [Preparar los agentes de programación](/docs/cli/init#preparar-los-agentes-de-programación). `--dry-run` muestra los archivos sin escribirlos.

O, sin la CLI, añade solo el servidor MCP a tu perfil de usuario de VS Code; usa una vía, nunca las dos:
