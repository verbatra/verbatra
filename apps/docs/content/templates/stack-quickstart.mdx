```bash
npm install --save-dev @verbatra/cli
```

verbatra is a development tool and never ships in your app. In a project without a `package.json`, such as a Flutter app, npm creates one; add `node_modules/` to its `.gitignore`. ## What just happened

- `verbatra.lock.json` records a hash of each source string, so the next run sends only new and changed strings. See [The lock file](/docs/the-lock-file).
- A result that drops a placeholder is withheld, never written. See [Translation safety](/docs/translation-safety).
- `npx verbatra check` exits `1` once a locale falls out of sync, so it can gate a pull request.

Commit the locale files, `verbatra.lock.json`, and `verbatra.provenance.json` together.
