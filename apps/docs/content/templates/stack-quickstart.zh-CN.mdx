学完本页，你的 <StackText field="name" /> 应用会显示一条由 verbatra 从 <StackText field="sourceFile" /> 翻译而来的德语字符串，并且锁文件会让之后的每次运行只翻译已更改的内容。你需要 Node.js `^22.22.0 || >=24`、一个 <StackText field="name" /> 项目，以及大约 10 分钟。前四步不需要账号，也不需要 API 密钥。

## 刚才发生了什么

- `verbatra.lock.json` 记录每条源字符串的哈希，因此下次运行只发送新增和已更改的字符串。见[锁文件与来源记录](/zh-CN/docs/the-lock-file)。
- 丢失占位符的译文会被搁置，绝不会写入。见[翻译安全](/zh-CN/docs/translation-safety)。

把语言文件、`verbatra.lock.json` 和 `verbatra.provenance.json` 一起提交。

## 可选：连接你的编码智能体

<AvailableFrom version="0.12.0" />

```bash
npx @verbatra/cli init --agent
```

配置已就位时，`init --agent` 保留它，只添加智能体文件：写入 `AGENTS.md` 的 verbatra 规则（如果 `CLAUDE.md` 是你唯一的指令文件，则写入 `CLAUDE.md`），以及在它检测到的每个编码智能体的项目配置中注册 verbatra MCP 服务器（不允许花费）。它为哪个智能体写入哪些文件，以及用 `--client` 自己指定智能体，见[配置编码智能体](/zh-CN/docs/cli/init#配置编码智能体)。`--dry-run` 显示这些文件，但不写入。

或者，不用 CLI，只把 MCP 服务器添加到你的 VS Code 用户配置文件；只用其中一种方式，不要两种都用：
