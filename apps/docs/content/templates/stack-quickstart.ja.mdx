このページを終えると、<StackText field="name" /> アプリに、verbatra が <StackText field="sourceFile" /> から翻訳したドイツ語の文字列が表示されます。以降の実行では、ロックファイルのおかげで変更された分だけが翻訳されます。必要なものは、Node.js `^22.22.0 || >=24`、<StackText field="name" /> プロジェクト、10 分ほどの時間です。最初の 4 つの手順には、アカウントも API キーも必要ありません。

すでにロケールファイルとコーディングエージェントがある場合は、代わりに [AI エージェントで verbatra をセットアップする](/ja/docs/start-with-ai)のプロンプトをエージェントに渡します。エージェントはプロジェクトにあるファイルに合わせて作業し、費用が発生する前に止まります。

## ここで起きたこと

- `verbatra.lock.json` が各ソース文字列のハッシュを記録します。そのため、次回の実行では新しい文字列と変更された文字列だけが送られます。[ロックファイルと来歴](/ja/docs/the-lock-file)を参照してください。
- プレースホルダーが失われた結果は保留され、書き込まれません。[翻訳の安全性](/ja/docs/translation-safety)を参照してください。

ロケールファイル、`verbatra.lock.json`、`verbatra.provenance.json` は、まとめてコミットします。

## 任意：コーディングエージェントを接続する

<AvailableFrom version="0.12.0" />

```bash
npx @verbatra/cli init --agent
```

設定ファイルがすでにある場合、`init --agent` は変更を加えず、エージェント用のファイルだけを追加します。追加されるのは、`AGENTS.md` の verbatra のルール（指示ファイルが `CLAUDE.md` だけの場合は `CLAUDE.md`）と、検出した各コーディングエージェントのプロジェクト設定に登録する verbatra MCP サーバー（課金はオフ）です。どのエージェントにどのファイルを書き込むか、また `--client` でエージェントを自分で指定する方法は、[コーディングエージェントを設定する](/ja/docs/cli/init#コーディングエージェントを設定する)にあります。`--dry-run` を付けると、ファイルを書き込まずに表示します。

CLI を使わずに、MCP サーバーだけを VS Code のユーザープロファイルに追加することもできます。どちらか一方の方法だけを使い、両方は使わないでください。
