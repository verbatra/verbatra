Cette page s'adresse à un projet qui a déjà des fichiers de locale commités. Colle le prompt ci-dessous dans ton agent IA de code (Claude Code, Cursor ou tout agent capable d'ouvrir un lien et d'exécuter des commandes shell). Il suit les étapes de cette page et te demande avant d'appeler réellement un fournisseur.

## Le prompt

```text
Set up verbatra here by following https://verbatra.kreitz-webdev.de/docs/start-with-ai.md. Spend nothing until I confirm. Never write or ask for an API key. If the link fails, stop.
```

## Les étapes que suit l'agent

Le prompt envoie l'agent vers la version Markdown de cette page. Agent : suis ces étapes dans l'ordre et ne saute jamais l'arrêt de l'étape 7.

### 1. Examiner la configuration existante

Avant de modifier quoi que ce soit, trouve la bibliothèque i18n dans `package.json` (par exemple `i18next`, `vue-i18n`, `next-intl` ou `@ngx-translate/core`) et les fichiers de locale eux-mêmes. Note la locale source, chaque locale cible déjà présente et le motif de chemin avec un jeton `{locale}`, comme `locales/{locale}.json`. [Choisis ta stack](/docs/pick-your-stack) associe à chaque stack son id de format et sa structure ; [Formats](/docs/formats) indique quels fichiers doivent déjà exister, comme un fichier XLIFF ou un Xcode String Catalog. Du JSON sans bibliothèque i18n : des marqueurs `{{name}}` signifient `i18next-json`, une accolade simple `{name}` signifie `vue-i18n-json`. Un projet Android utilise `res/{locale}/strings.xml` avec `files.localeStyle: "android"`, si bien que le jeton devient `values` et `values-de`.

### 2. Installer la CLI

```bash
npm install --save-dev @verbatra/cli
```

pnpm, yarn et bun fonctionnent aussi. Si pnpm se termine avec `ERR_PNPM_IGNORED_BUILDS`, lance `pnpm approve-builds` une fois sans approuver aucune des deux entrées. Si npm signale des scripts d'installation que `allowScripts` ne couvre pas, laisse-les non approuvés : verbatra n'en a besoin d'aucun.

### 3. Créer la config sans questions

```bash
npx verbatra init --provider <provider> --yes --json
```

Demande à l'humain quel fournisseur utiliser, sauf si le projet le rend déjà évident. [Fournisseurs](/docs/providers) liste les ids ; `none` désactive la traduction automatique. Ne choisis jamais un fournisseur qui dépense sur un service que l'humain n'a pas accepté, et ne passe jamais une valeur de clé à `init`. `init` détecte le format, le motif de chemin et les locales, affiche une enveloppe JSON et ne pose jamais de question :

- Sortie `0` : compare `result.config` avec ce que tu as trouvé à l'étape 1, en commençant par chaque entrée de `result.sources` qui indique `default` ; `result.config.files.localeStyle` n'apparaît que si les fichiers n'écrivent pas les locales telles quelles, et `result.detection.layout` montre le motif et les locales trouvés par l'analyse. Si quelque chose ne va pas, relance-la avec le bon `--format`, `--path`, `--source` ou `--targets`, plus `--force`.
- Sortie `2` avec `FORMAT_AMBIGUOUS` ou `LAYOUT_AMBIGUOUS` : choisis parmi les `candidates` et relance-la avec `--format` ou `--path`. Si les candidats sont des fichiers de namespace côte à côte, arrête-toi et demande à l'humain, car une config couvre un seul motif de fichier.
- Sortie `2` avec `MISSING_OPTIONS` : le message nomme chaque flag encore nécessaire.
- Sortie `2` avec `CONFIG_EXISTS` : demande à l'humain avant de passer `--force`.

[init](/docs/cli/init#fournisseurs) documente chaque flag, y compris `--base-url` et `--model` pour un serveur compatible OpenAI ou LibreTranslate.

### 4. Laisser la clé d'API à l'humain

Saute cette étape avec le fournisseur `none`.

```bash
cp .env.example .env
```

Vérifie que `.env` nomme la variable de `result.apiKeyEnvVar`, laisse sa valeur vide et dis à l'humain quelle variable remplir. N'écris, n'invente ni ne demande jamais une valeur de clé. Continue sans l'attendre.

### 5. Lancer doctor

```bash
npx verbatra doctor --json
```

`doctor` lit le nom de la variable de clé dans l'environnement ou dans `.env.local` et `.env`, jamais sa valeur. Corrige chaque vérification en échec que tu peux corriger en modifiant `verbatra.config.ts`, puis relance-la. La vérification `api-key` ne passe qu'une fois que l'humain a défini la clé, alors ne boucle pas dessus.

### 6. Prévisualiser sans dépenser

```bash
npx verbatra check --json
npx verbatra diff --json
npx verbatra translate --dry-run --json
```

Aucune de ces commandes n'appelle de fournisseur, ne demande de clé ni n'écrit de fichier. La sortie `1` de `check` ou `diff` signifie qu'une locale n'est pas synchronisée, ce qui est attendu avant une première exécution ; seule la sortie `2` signale un problème de configuration. Avec le fournisseur `none`, `translate --dry-run` sort avec `3` quand des clés restent pour un traducteur humain, ce qui est aussi attendu. verbatra n'écrase jamais une valeur existante, même à la première exécution : seules les clés absentes de la cible sont traduites. Une chaîne vide compte comme une valeur existante, alors demande à l'humain avant de supprimer des clés de remplissage `""`.

### 7. S'arrêter et demander

Résume combien de clés sont en attente par locale et ce que `translate --dry-run` a indiqué, puis arrête-toi. Une vraie exécution dépense tout de suite et n'a pas de confirmation propre, alors attends le feu vert explicite de l'humain. N'utilise jamais `--prune` sauf si l'humain a demandé de supprimer les clés orphelines.

### 8. Traduire après le feu vert

```bash
npx verbatra translate --json
```

Rapporte les listes `succeeded`, `partial` et `failed` du résumé. Une locale `partial` ou `failed` a quand même été écrite avec tout ce qui a réussi.

### 9. Committer les bons fichiers

Committe `verbatra.config.ts`, `.env.example`, `verbatra.lock.json`, `verbatra.provenance.json` une fois qu'une exécution l'a écrit, et les fichiers de locale traduits. Ne committe jamais `.env`, `.env.local`, `.verbatra-local/` ni `verbatra.cache.json` ; `init` les a ajoutés au `.gitignore`, alors vérifie qu'ils sont bien ignorés.

## Pourquoi cette forme

`translate` n'a pas de garde-fou de dépense qui lui soit propre, donc ce garde-fou vit dans les instructions de l'agent : chaque étape avant la 8 est gratuite et en lecture seule.
