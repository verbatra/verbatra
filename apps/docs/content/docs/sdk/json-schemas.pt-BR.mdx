Todo `result` que a CLI imprime com `--json` tem um schema zod 4 no SDK, fixado em tempo de compilação ao tipo TypeScript que ele descreve: os mesmos campos, os mesmos campos opcionais e os mesmos tipos de valor, de modo que uma mudança em um sem o outro quebra o build. O `parse` dele também aceita um valor de um verbatra mais novo: ele permite campos que não lista e os remove do resultado. Os mesmos schemas são publicados como documentos JSON Schema; as URLs deles e a regra de versionamento estão em [Códigos de saída e saída JSON](/pt-BR/docs/cli/output#schemas).

## Publicação

`SDK_JSON_SCHEMAS` lista todos os documentos que o SDK publica em `@verbatra/sdk/schemas/`, cada um com o seu `name`, `title`, `io` e o `schema` zod. `JSON_SCHEMA_BASE_URL` é `https://verbatra.kreitz-webdev.de/schema/v1/`. `KNOWN_ERROR_CODES` lista todos os códigos de erro do SDK, dos provedores e dos adaptadores; o schema do envelope de erro (o objeto JSON da resposta) os oferece como sugestão, mas aceita qualquer código.

### renderJsonSchemas

Gera os próprios documentos JSON Schema do verbatra (draft 2020-12) a partir de uma lista de `JsonSchemaDocument`, indexados pelo nome. Cada um recebe o `$id` que `jsonSchemaUrl` dá ao nome dele, uma URL neste site, então use a função apenas para os documentos do verbatra e `renderOutputJsonSchema` para um schema seu. Um documento de saída permite toda propriedade que não lista; um documento de entrada, como a configuração, mantém os objetos fechados. Um schema que embute um documento de qualquer uma das listas faz referência a ele por URL.

```ts title="Assinatura"
function renderJsonSchemas(
  documents: readonly JsonSchemaDocument[],
  references?: readonly JsonSchemaDocument[],
): Readonly<Record<string, JsonSchemaObject>>;
```

**Retorna:** um documento por entrada de `documents`, cada um com `$schema`, `$id` e `title`.

### renderOutputJsonSchema

Gera o JSON Schema de um schema zod do mesmo modo que os documentos de saída são gerados, sem um `$id`, por exemplo para o `outputSchema` de uma ferramenta MCP.

```ts title="Assinatura"
function renderOutputJsonSchema(schema: z.ZodType): JsonSchemaObject;
```

**Retorna:** `JsonSchemaObject`

### jsonSchemaUrl

Retorna a URL pública de um documento publicado, que também é o `$id` dele: `jsonSchemaUrl("run-summary")` é `https://verbatra.kreitz-webdev.de/schema/v1/run-summary.json`.

```ts title="Assinatura"
function jsonSchemaUrl(name: string): string;
```

**Retorna:** `string`
