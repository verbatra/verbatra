Cada `result` que la CLI imprime con `--json` tiene un esquema de zod 4 en el SDK, fijado en tiempo de compilación al tipo de TypeScript que describe: los mismos campos, los mismos campos opcionales y los mismos tipos de valor, así que cambiar uno sin el otro hace fallar la compilación. Su `parse` también acepta un valor de un verbatra más nuevo: admite campos que no enumera y los elimina del resultado. Los mismos esquemas se publican como documentos JSON Schema; sus URL y la regla de versiones están en [Códigos de salida y salida JSON](/docs/cli/output#esquemas).

## Publicación

`SDK_JSON_SCHEMAS` enumera cada documento que el SDK publica en `@verbatra/sdk/schemas/`, cada uno con su `name`, `title`, `io` y su `schema` de zod. `JSON_SCHEMA_BASE_URL` es `https://verbatra.kreitz-webdev.de/schema/v1/`. `KNOWN_ERROR_CODES` enumera cada código de error del SDK, de los proveedores y de los adaptadores; el esquema del envoltorio de error los ofrece como sugerencia y acepta cualquier código.

### renderJsonSchemas

Genera los documentos JSON Schema propios de verbatra (draft 2020-12) a partir de una lista de `JsonSchemaDocument`, indexados por nombre. Cada uno recibe el `$id` que `jsonSchemaUrl` da a su nombre, una URL de este sitio, así que úsalo solo para los documentos de verbatra y `renderOutputJsonSchema` para un esquema propio. Un documento de salida admite cualquier propiedad que no enumera; un documento de entrada, como la configuración, conserva sus objetos cerrados. Un esquema que incluye un documento de cualquiera de las dos listas lo referencia por URL.

```ts title="Firma"
function renderJsonSchemas(
  documents: readonly JsonSchemaDocument[],
  references?: readonly JsonSchemaDocument[],
): Readonly<Record<string, JsonSchemaObject>>;
```

**Devuelve:** un documento por cada entrada de `documents`, cada uno con `$schema`, `$id` y `title`.

### renderOutputJsonSchema

Genera el JSON Schema de un solo esquema zod tal como se generan los documentos de salida, sin `$id`, por ejemplo para el `outputSchema` de una herramienta MCP.

```ts title="Firma"
function renderOutputJsonSchema(schema: z.ZodType): JsonSchemaObject;
```

**Devuelve:** `JsonSchemaObject`

### jsonSchemaUrl

Devuelve la URL pública de un documento publicado, que también es su `$id`: `jsonSchemaUrl("run-summary")` es `https://verbatra.kreitz-webdev.de/schema/v1/run-summary.json`.

```ts title="Firma"
function jsonSchemaUrl(name: string): string;
```

**Devuelve:** `string`
