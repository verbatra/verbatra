Chaque `result` que la CLI affiche avec `--json` a un schéma zod 4 dans le SDK, lié à la compilation au type TypeScript qu'il décrit : les mêmes champs, les mêmes champs optionnels et les mêmes types de valeur, si bien que changer l'un sans l'autre fait échouer la compilation. Son `parse` accepte aussi une valeur venant d'un verbatra plus récent : il admet les champs qu'il ne liste pas et les retire du résultat. Les mêmes schémas sont publiés comme documents JSON Schema ; leurs URL et la règle de versions se trouvent sur [Codes de sortie et sortie JSON](/fr/docs/cli/output#schémas).

## Publication

`SDK_JSON_SCHEMAS` liste chaque document que le SDK publie sous `@verbatra/sdk/schemas/`, chacun avec son `name`, son `title`, son `io` et son `schema` zod. `JSON_SCHEMA_BASE_URL` vaut `https://verbatra.kreitz-webdev.de/schema/v1/`. `KNOWN_ERROR_CODES` liste chaque code d'erreur du SDK, des fournisseurs et des adaptateurs ; le schéma de l'enveloppe d'erreur les propose comme indication tout en acceptant n'importe quel code.

### renderJsonSchemas

Génère les documents JSON Schema propres à verbatra (draft 2020-12) à partir d'une liste de `JsonSchemaDocument`, indexés par nom. Chacun reçoit le `$id` que `jsonSchemaUrl` donne à son nom, une URL de ce site : utilise-le donc seulement pour les documents de verbatra, et `renderOutputJsonSchema` pour un schéma à toi. Un document de sortie accepte toute propriété qu'il ne liste pas ; un document d'entrée, comme la configuration, garde ses objets fermés. Un schéma qui intègre un document de l'une des deux listes y renvoie par URL.

```ts title="Signature"
function renderJsonSchemas(
  documents: readonly JsonSchemaDocument[],
  references?: readonly JsonSchemaDocument[],
): Readonly<Record<string, JsonSchemaObject>>;
```

**Renvoie :** un document par entrée de `documents`, chacun avec `$schema`, `$id` et `title`.

### renderOutputJsonSchema

Génère le JSON Schema d'un seul schéma zod comme sont générés les documents de sortie, sans `$id`, par exemple pour l'`outputSchema` d'un outil MCP.

```ts title="Signature"
function renderOutputJsonSchema(schema: z.ZodType): JsonSchemaObject;
```

**Renvoie :** `JsonSchemaObject`

### jsonSchemaUrl

Renvoie l'URL publique d'un document publié, qui est aussi son `$id` : `jsonSchemaUrl("run-summary")` vaut `https://verbatra.kreitz-webdev.de/schema/v1/run-summary.json`.

```ts title="Signature"
function jsonSchemaUrl(name: string): string;
```

**Renvoie :** `string`
