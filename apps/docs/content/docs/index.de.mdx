<DocsHomeSection title="Jeder Lauf ist ein Diff, kein Rewrite." lead="Was passiert, wenn du verbatra translate ausführst.">

Eine Quell-Locale von Hand zu pflegen bedeutet, dass jede andere Locale-Datei abdriftet: Neue Keys fehlen in den Zielen, bearbeitete Strings hinterlassen veraltete Übersetzungen, und gelöschte Keys bleiben als Waisen zurück. verbatra schließt diese Lücke, indem es jedes Ziel gegen eine committete Lock-Datei, `verbatra.lock.json`, vergleicht und nur das Geänderte an den von dir konfigurierten Provider sendet; ein zweiter Lauf ohne etwas Neues macht überhaupt keinen Provider-Aufruf. Jedes Ergebnis wird vor dem Schreiben geprüft, sodass ein kaputter Platzhalter zurückgehalten und erneut versucht wird, statt ausgeliefert zu werden. Siehe [Wie es funktioniert](/docs/how-it-works) für die vollständige Pipeline.

<DocsHomeSteps />

verbatra liest und schreibt vierzehn Formate und übersetzt über sechs Provider hinter einer einzigen Schnittstelle; ein Format, das es nicht mitbringt, lässt sich als [eigener Adapter](/docs/custom-format-adapters) ergänzen. Siehe [Formate](/docs/formats) und [Provider](/docs/providers).

</DocsHomeSection>
