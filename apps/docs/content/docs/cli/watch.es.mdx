---
title: verbatra watch
description: Retraduce en cada cambio del origen hasta que lo interrumpas.
---
Vigila el archivo del locale de origen y vuelve a ejecutar una traducción en cada cambio, con anti-rebote, hasta que lo interrumpas. `watch` ejecuta una traducción inicial al arrancar y luego mantiene al día tus locales de destino mientras guardas. Antes de ejecutarse, carga `.env.local` y luego `.env` desde el directorio de trabajo; una variable ya definida en el entorno real gana.

## Sinopsis

```bash
verbatra watch [flags]
```

## Flags

| Flag | Argumento | Por defecto | Efecto |
| --- | --- | --- | --- |
| `--cwd` | `<path>` | directorio actual | resuelve la configuración y los archivos de locale desde este directorio |
| `--config` | `<path>` | busca uno | carga este archivo de configuración en lugar de buscar uno |
| `--locales` | `<list>` | todos los locales de destino configurados | vigila y traduce solo este subconjunto separado por comas; un locale no configurado se rechaza al arrancar con `UNKNOWN_LOCALE` antes de empezar a vigilar nada, y una lista vacía es un error de uso, salida `2` |
| `--debounce` | `<ms>` | `300` | espera estos milisegundos tras el último cambio antes de traducir; debe ser un entero positivo sin sufijo (un valor como `250ms`, `0` o `-1` es un error de uso, salida `2`) |
| `--lock-timeout` | `<seconds>` | `600` | cuánto tiempo esperar a un bloqueo de escritura por locale que ya está tomado antes de fallar; debe ser un entero positivo sin sufijo, en segundos (un valor como `60s`, `0` o `-1` es un error de uso, salida `2`) |
| `--concurrency` | `<n>` | `1` | traduce hasta `n` locales de destino a la vez por ejecución; debe ser un entero positivo |
| `--no-cache` | ninguno | desactivado (caché activada) | omite la [caché de memoria de traducción](/docs/the-cache) local (`verbatra.cache.json`) en cada ejecución |
| `--json` | ninguno | desactivado | imprime cada ejecución como un [envoltorio JSON](/docs/ci-and-exit-codes#salida-json) en stdout, al estilo NDJSON (un objeto por línea) |

Con `--json`, cada ejecución emite un registro [envoltorio](/docs/ci-and-exit-codes#salida-json) con `command: "watch"`: un registro `ok: true` que lleva el [`RunSummary`](/docs/sdk) de esa ejecución bajo `result`, o un registro `ok: false` que lleva un código de error y un mensaje. La línea de arranque, el aviso de parada y el progreso de cada ejecución van a stderr, así que el flujo de stdout se mantiene como NDJSON limpio. Una ejecución fallida es solo un registro en el flujo: ni detiene el watcher ni cambia el código de salida.

`--locales de,fr` reduce cada ciclo de la sesión a un subconjunto de los destinos configurados, lo que mantiene barato un bucle de desarrollo cuando solo te importa un idioma. El subconjunto se valida una sola vez al arrancar, no en cada ejecución.

`--lock-timeout` se aplica a cada ciclo: ajusta cuánto espera un locale a un [bloqueo de escritura](/docs/the-lock-file) disputado antes de que esa ejecución falle con `LOCK_CONTENDED`. Una ejecución fallida es solo un registro en el flujo, así que el watcher sigue de todas formas.

`--concurrency` se aplica a la ejecución de cada ciclo. Cada ejecución recibe un presupuesto de tokens nuevo, y un `--concurrency` mayor que `1` se sigue rechazando cuando la configuración fija un presupuesto `maxTokens`, porque qué locale pierde su trabajo restante dependería del orden en que los locales se entrelacen: `watch` rechaza esa combinación al arrancar y sale con `2` antes de la ejecución inicial, en lugar de arrancar una sesión que falla en cada ciclo. `--no-cache` omite la [caché de memoria de traducción](/docs/the-cache) en cada ciclo.

## Detención

La primera interrupción (Ctrl-C, o SIGTERM) deja terminar la ejecución en curso, detiene el watcher limpiamente y sale con `0`. Una segunda interrupción mientras esa parada sigue en curso fuerza la detención con salida `130`.

## Ejemplos

```bash
# watch and re-translate on each change
verbatra watch

# calmer in a busy editor: wait 1s after the last change, stream NDJSON
verbatra watch --debounce 1000 --json

# keep only German current while you work
verbatra watch --locales de
```

## Códigos de salida

| Código | Significado |
| --- | --- |
| `0` | detenido limpiamente por una sola interrupción |
| `2` | no se pudo arrancar o detener: un error de configuración, un fallo de arranque o de parada, o un error de uso (incluido un `--debounce` inválido) |
| `130` | detenido a la fuerza por una segunda interrupción |
