`verbatra report provenance` lee `verbatra.provenance.json`, el archivo de bloqueo y los archivos de
locale, e imprime por locale de destino cuántos valores escribió una máquina sin que nadie los
revisara, cuántos revisó una persona, cuántos escribieron o importaron personas y de cuántos no
puede dar cuenta verbatra. Con `--json` lista el origen, el estado de revisión, el proveedor, el
modelo y el revisor de cada clave, para un archivo de auditoría. No llama a ningún proveedor, no
necesita clave de API y no escribe nada.

El informe es evidencia de apoyo de qué texto generó una máquina, no asesoramiento jurídico.
[Evidencia de traducción automática](/docs/provenance-evidence) explica qué puede y qué no puede
mostrar, los grupos y el esquema JSON completo.

## Sinopsis

```bash
verbatra report <report> [flags]
```

`<report>` nombra el informe que se imprime. `provenance` es el único por ahora; cualquier otro nombre
es un error de uso.

## Flags

| Flag | Argumento | Por defecto | Efecto |
| --- | --- | --- | --- |
| `--cwd` | `<path>` | directorio actual | resuelve la configuración y los archivos de locale desde este directorio |
| `--config` | `<path>` | busca uno | carga este archivo de configuración en lugar de buscar uno |
| `--locales` | `<list>` | todos los destinos configurados | subconjunto de locales de destino separado por comas del que informar |
| `--json` | ninguno | desactivado | imprime en stdout un [envoltorio JSON](/docs/ci-and-exit-codes#salida-json) con el informe bajo `result`, con todas las claves, o el código de error en una ejecución fallida; la línea de error legible sigue yendo a stderr |

No hay `--out`: el informe va a stdout, como `check` y `diff`, así que redirígelo para conservarlo
(`verbatra report provenance --json > provenance-report.json`). Un valor `--locales` vacío o
desconocido se rechaza con salida `2`.

## Ejemplos

```bash
# counts per locale: machine and unreviewed, machine and reviewed, human, imported, and the rest
verbatra report provenance

# every key's origin and review state, for an audit file
verbatra report provenance --json > provenance-report.json

# only the German locale
verbatra report provenance --locales de
```

## Salida

```text
verbatra report provenance (source en, verbatra 0.12.0, 2026-09-29T08:00:00.000Z)
  locale  machine, unreviewed  machine, reviewed  human  import  external  unrecorded  unknown  total
  de      12                   40                 3      85      1         0           0        141
Supporting evidence from verbatra.provenance.json, not legal advice. --json lists every key.
```

La primera línea nombra el locale de origen, la versión de verbatra y cuándo se hizo el informe. Cada
fila cuenta las claves que tienen un valor tanto en el origen como en ese locale. Los grupos se
describen en [Evidencia de traducción automática](/docs/provenance-evidence#el-informe-de-procedencia).

## Información en el terminal

El comando muestra una línea mientras lee los archivos. Cuando hay traducciones automáticas
esperando revisión, sugiere Studio:

```text
verbatra: reading the provenance record... done (0.1s)
next: verbatra studio (approve or reject the 12 machine translations no person has reviewed yet)
```

Estas líneas van a stderr, así que stdout y la salida `--json` quedan exactamente como se describe
arriba, y `--quiet` las omite. Consulta [Salida en el terminal](/docs/cli#salida-en-el-terminal).

## Códigos de salida

| Código | Significado |
| --- | --- |
| `0` | se imprimió el informe |
| `1` | sin informe: `verbatra.provenance.json` está corrupto o lo escribió un verbatra más nuevo. Con `--json` el resultado es `{ "available": false, "reason": "provenance-unreadable" }` |
| `2` | no se pudo ejecutar: un error de configuración, un archivo de origen o de bloqueo ilegible, un valor `--locales` vacío o desconocido, o un nombre de informe desconocido |

Un informe construido sin un archivo de procedencia legible listaría cada valor como `unrecorded`, lo
que no es lo mismo que no tener registro. Por eso el comando falla en cerrado, como
[`check --require-reviewed`](/docs/cli/check), para que un job de CI no archive un archivo de
auditoría vacío.
