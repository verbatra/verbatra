---
title: verbatra export
description: Exporta las cadenas sin traducir a una entrega para traductores, como libro de Excel con estilos o como un archivo CSV o TSV por locale.
---
Escribe las cadenas que necesitan traducción en un libro de Excel con estilos que un humano puede rellenar y devolver para [`verbatra import`](/docs/cli/import). Por defecto el libro lleva solo las cadenas faltantes y modificadas: las mismas claves que una ejecución automática enviaría a un proveedor. `export` nunca llama a un proveedor y no necesita clave de API.

## Sinopsis

```bash
verbatra export [flags]
```

## Flags

| Flag | Argumento | Por defecto | Efecto |
| --- | --- | --- | --- |
| `--cwd` | `<path>` | directorio actual | resuelve la configuración y los archivos de locale desde este directorio |
| `--config` | `<path>` | busca uno | carga este archivo de configuración en lugar de buscar uno |
| `--out` | `<path>` | `verbatra-translations.xlsx`, o `verbatra-translations` para `csv` y `tsv` | escribe la entrega aquí: una ruta de archivo para `xlsx`, un directorio para `csv` y `tsv` |
| `--format` | `<format>` | `xlsx` | escribe un libro de Excel (`xlsx`) o un archivo delimitado por locale (`csv`, `tsv`) |
| `--locales` | `<list>` | todos los destinos configurados | subconjunto de locales de destino que exportar, separados por comas |
| `--include-unchanged` | ninguno | desactivado | exporta también las cadenas que ya están al día |
| `--json` | ninguno | desactivado | imprime un [envoltorio JSON](/docs/ci-and-exit-codes#salida-json) en stdout que lleva el resultado de la exportación (ruta y número de filas por locale) bajo `result`, o el código de error si la ejecución falla; la línea de error legible por humanos sigue yendo a stderr |

Un valor `--locales` vacío o desconocido se rechaza con salida `2` en lugar de exportar nada en silencio.

## Ejemplos

```bash
# write the workbook with missing and changed strings
verbatra export

# only the German and French sheets, to a specific path
verbatra export --locales de,fr --out handoff/round-2.xlsx

# one de.csv and fr.csv under handoff/
verbatra export --format csv --out handoff
```

## CSV y TSV

`--format csv` y `--format tsv` escriben texto plano en lugar de un libro: un `<locale>.csv` o `<locale>.tsv` por cada locale exportado, con las mismas columnas y en el mismo orden que una hoja del libro. `--out` nombra entonces el directorio donde se escriben los archivos, y el directorio se crea si falta.

Un archivo delimitado se puede comparar con diff y se abre en cualquier parte, pero no lleva protección de celdas: todas las columnas son editables y la columna `Source hash` es visible. Un hash editado nunca se da por bueno: la importación lo compara con la fuente viva y retiene la fila.

Cada exportación delimitada escribe además un manifiesto oculto en el directorio, `.verbatra-export-csv.json` o `.verbatra-export-tsv.json`, que nombra los locales que acaba de escribir. Es lo que permite que una reexportación con una selección `--locales` más estrecha retire los locales que ha dejado fuera: sus archivos siguen en disco, y [`verbatra import`](/docs/cli/import) los rechaza como restos en lugar de aplicar una traducción desactualizada. La exportación no borra nada del directorio de salida, así que un archivo tuyo que esté ahí nunca corre peligro.

## Códigos de salida

| Código | Significado |
| --- | --- |
| `0` | la entrega se escribió |
| `2` | no se pudo ejecutar: un error de toda la ejecución, o un error de uso (incluido un valor `--locales` vacío o desconocido) |

`export` no tiene modo de fallo por locale, así que nunca sale con `1`.

Un locale de destino que no puede dar nombre a su hoja o a su archivo detiene la exportación con `WORKBOOK_INVALID`. El nombre de una hoja xlsx debe tener de 1 a 31 caracteres, no debe contener ninguno de `: \ / ? * [ ]` y no debe coincidir con `Instructions` ni con el nombre de hoja de otro locale de destino, sin distinguir mayúsculas. El nombre de un archivo `csv` o `tsv` no debe estar vacío, ni ser `.` o `..`, y no debe contener un separador de ruta, un carácter de control ni ninguno de `: * ? " < > |`. El mismo código cubre un libro que no se pudo serializar.
