Studio now uses a top navigation bar like the verbatra docs; the sidebar is gone.

- **Navigation:** Overview, Translations, Review, Glossary and Settings are links in the header, with the current page marked. Review shows how many entries wait. On small screens a menu button opens the same links in a drawer.
- **Search:** the header search opens the Translations list filtered by what you typed, and the address keeps it (`#/translations?q=...`).
- **Links:** the header links to the documentation and to GitHub, next to the theme toggle and the connection notice.
- **Keyboard:** a skip link moves focus past the header to the page content.
